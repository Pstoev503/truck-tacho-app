**Дата:** 2026-10-17 · **Статус:** предадено за преглед; не е внедрено.

## Възлагане и вход

Възложени са само интерфейсен договор, правила за качество, детерминирани сценарии и отчет. Вход: прикачен `Top10EU.zip`, SHA-256 `b4ca9847f91309763c3170d82cdb3bf687692a8e8a5e3ba77ed1d6940ba1578b` (проверен локално). Не е доказано съответствие с GitHub. Координационни Git refs **предоставени от отговорника, не използвани като baseline**: `main@26ef2442910757d4427670de38d61d6b78d1ad99`, `shef@449dc5e047e9e71b5fdd0c9a22a3331b8e16e4be`, PR #7; PR #9/#11 са чужда документационна работа. В ZIP не са открити целевите четири пътя. Не е правена проверка на същите пътища в текущата локална папка/актуалния Git branch.

## Извършено

- Написан provider-neutral логически договор за заявка/отговор с routeRevision, UTC departure, ordered segments, geometry, direction, vehicle profile, expectedEntryAt и timestamp provenance.
- Разделени routing base, measured, historical, forecast и incident constraints/effects; дефинирани replacement/adjustment и защита от двойно броене.
- Описани source IDs, версии, correction/cancellation/expiry, incremental/full snapshot, идемпотентност, cross-source dedup и конфликтни данни.
- Дефинирани геопривързване и неопределеност; до 3 оценки на една routeRevision с unstable flag.
- Дефинирани quality statuses, fallback без live, липсващи данни ≠ нула, forecast без валидиран модел = unavailable.
- Добавени 6 **синтетични** валидни JSON request/response двойки и 24 детерминирани приемателни сценария.
- Описани логически исторически записи и лицензионни/retention условия без DDL.

## Проверки и ограничения

- Локално потвърден SHA-256 на предоставения ZIP и отсъствие на четирите целеви пътя в него.
- Синтетичните JSON примери са генерирани с Python `json.dumps` и ще бъдат повторно валидирани с `json.loads` при финалната проверка.
- Няма изпълнен integration/unit test срещу Top10EU runtime, няма реален DATEX feed, няма живо проверени provider профили, лицензни условия или API SLA. Първични ориентири: https://datex2.eu/ ; https://transport.ec.europa.eu/transport-themes/smart-mobility/road/its-directive-and-action-plan/national-access-points_en ; https://eur-lex.europa.eu/eli/reg_del/2022/670/oj . Дата на подготовка 2026-10-17; страниците не са live потвърдени в този пакет.
