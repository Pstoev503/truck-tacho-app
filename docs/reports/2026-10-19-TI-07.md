## Public API
`createValidatedTrafficCycle({evaluate,plan,createRequest,getEvaluationContext})` requires all four callbacks. It constructs the **unchanged** `createTrafficCycle` with an internal non-overridable `validate` callback that always calls the accepted `validateTrafficExchangeWithSourceHealth`. Returns only `{run,cancel,snapshot}`, preserving 3-attempt budget, reuse, supersession and cancellation.

For each actual evaluated response, the synchronous `getEvaluationContext({request,response})` receives defensive structured copies and returns `{evaluatedAt,maxExchangeAgeMs,sources}` per accepted TI-04/TI-06 schemas. No cache, clock or TTL default. Its `activeRequest` field is ignored; activeRequest comes exclusively from the cycle. Invalid/missing/throwing context returns generic `EVALUATION_CONTEXT_INVALID` or `EVALUATION_CONTEXT_ERROR`; accidental thenables return `EVALUATION_CONTEXT_ASYNC` and rejection is consumed without logging exception messages. No planner call on invalid exchange/context. Context copies do not freeze or mutate originals.
