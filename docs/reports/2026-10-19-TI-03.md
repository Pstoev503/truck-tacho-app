## API

`createTrafficCycle({evaluate,plan,createRequest,validate=validateTrafficExchange})` returns `{run,cancel,snapshot}`. `run({cycle,routeRevision,initialPlan,requestIds,inputRevisions})` uses caller-provided IDs, planner-provided `etaMs` and `segments[].expectedEntryAt`. Injected async callbacks supply request creation, traffic evaluation and replanning. Generation token prevents pending old response replacing current cycle; three attempts maximum. Convergence requires <=60 seconds ETA delta and matching explicit passability baseline. No HTTP, database, clock, real traffic feed, route calculation or internal pause calculation. No mutation of caller data is intended.
