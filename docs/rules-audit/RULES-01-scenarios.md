# RULES-01 — детерминирани гранични сценарии

Версия: `bdddd307c4729985ba82a34f2d3d4a0af67a71df` (PLAN-02). `tacho-rules.js` е идентичен с `shef@449dc5e`.

## Условия

- T0 = `2026-10-12T00:00:00Z` (понеделник 00:00 UTC). Всички времена са UTC. Записите са синтетични, без реални водачи.
- Нотация: `drive 270` = каране 270 мин, `rest 45` = почивка/пауза 45 мин, `work` = друга работа. Последователните записи са съседни, без празнини.
- За анализатора: `analyze(log, { now: края на последния запис, lastWeeklyRestEnd: T0 })`, освен ако е казано друго.
- За плановника: `buildPlan({ stages: [{ distanceKm, roadType: 'motorway' }], departure: T0, now: T0, activities })`. „Пълна история“ = `rest` от T0 − 8 × 24 ч до началото на зададените дейности, така че `historyCoverage.complete` е true.
- **Статус „изпълнен“** означава, че входът е пуснат срещу реалния код с временна сонда извън репото (Node v22.22.0, 18.10.2026), а „действително“ е буквалният изход. Сондите **не** са добавени като тестове в репото и не се отчитат като `node --test` pass. „Не е изпълнен“ означава, че очакването е изведено само от четене на кода и текста.
- „Съвпада“ = действителното отговаря на нормативното очакване. „Разминаване“ = основа за находка в `RULES-01.md`.

## Обобщение

- Изпълнени: 32 реда (S-01…S-20 с подварианти). От тях 21 съвпадат с нормативното очакване, а 11 са разминавания, които водят до R-01…R-08. Неизпълнени: 4 (S-21…S-24).
- Валидни (очаквано без нарушение) гранични случаи: S-01, S-04, S-06, S-09a, S-10a, S-11a, S-12c, S-13a, S-17a, S-18. Невалидни: S-05, S-07, S-08, S-09b, S-10b, S-11b, S-12a, S-13b, S-15a, S-17b.
- Нито един от тези сценарии не е тест в `engine/*.test.js`. Codex може да ги превърне в регресии по собствена преценка. Входовете по-горе са достатъчни за това.

## Пример за възпроизвеждане (S-15d)

```js
import { buildPlan } from './engine/plan.js';
const H = 3600e3, T0 = Date.parse('2026-10-12T00:00:00Z');
const activities = [
  { type: 'rest', start: T0 - 192 * H, end: T0 - 8 * H },
  { type: 'work', start: T0 - 8 * H, end: T0 }
];
const p = buildPlan({ stages: [{ distanceKm: 960, roadType: 'motorway' }],
  departure: T0, now: T0, activities, multiManning: true });
// p.confirmed === true, p.violations.length === 0
// същото с multiManning:false -> DAILY_REST, confirmed:false
```
